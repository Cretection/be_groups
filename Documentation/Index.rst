===================
Backend Group Kinds
===================

----

Backend Group Kinds turns TYPO3 backend user groups into **kinds**: small
building blocks with exactly one purpose (page tree entry points, file
mounts, access rights, languages, …) and **roles** that are composed of
these building blocks. Backend users only get roles.

This is the structure the official TYPO3 documentation recommends for
backend permissions – implemented as real group types with a guided user
interface instead of a naming convention.

    Originally created by Michael Klapper (2012). Read the story of the
    extension in :ref:`credits`.
