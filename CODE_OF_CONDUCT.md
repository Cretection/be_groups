# Code of Conduct

🇬🇧 English · 🇩🇪 [Deutsch](#verhaltenskodex)

This project follows the
[TYPO3 Code of Conduct](https://typo3.org/community/values/code-of-conduct).
By participating – in issues, pull requests, discussions or any other
channel – you agree to uphold it.

Please report unacceptable behavior to the maintainer at
<info@cretection.it> or to the TYPO3 Community Management as described in
the TYPO3 Code of Conduct.

---

## Verhaltenskodex

Für dieses Projekt gilt der
[TYPO3 Code of Conduct](https://typo3.org/community/values/code-of-conduct).
Wer mitwirkt – in Issues, Pull Requests, Diskussionen oder anderen Kanälen –,
verpflichtet sich, ihn einzuhalten.

Unangemessenes Verhalten bitte an den Maintainer unter <info@cretection.it>
oder an das TYPO3 Community Management melden, wie im TYPO3 Code of Conduct
beschrieben.
